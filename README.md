# ApexCoach Pro

Personal training app: workouts, runs, recovery, points, ranks, a leaderboard and coach chat. English and European Portuguese.

- **Android:** download the APK from Actions → *Build APEXCOACH Android APK* → Artifacts.
- **iPhone:** see [IOS.md](IOS.md).
- **Server setup** (accounts, leaderboard, chat): run [supabase/schema.sql](supabase/schema.sql) in a Supabase project.
